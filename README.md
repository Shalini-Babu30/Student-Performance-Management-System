# Student-Performance-Management-System
An Excel-based dashboard developed to monitor and analyze student academic performance using formulas, Pivot Tables, charts, and conditional formatting.

## 🚀 Features

- Student performance tracking
- Interactive dashboard
- Pivot Tables
- Charts and visualizations
- Conditional Formatting
- Automated calculations

## 🛠️ Tools Used

- Microsoft Excel


## 📊 Dashboard Highlights

- Student Marks Analysis
- Subject-wise Performance
- Average Score
- Performance Charts
- Summary Dashboard
